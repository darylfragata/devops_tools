# devops_tools

A personal DevOps cheatsheet and toolkit, focused on productivity: quick-reference commands/notes for things I'd otherwise have to look up again, plus small tools built to cut down manual day-to-day work. Built while upskilling in DevOps tools, practices, and workflows, with AI-assisted development as part of the process.

## Reference

- [`git/`](git) - Git guidelines, merging strategies, and pull request workflow
- [`terraform/`](terraform) - Terraform command reference and HCL expression/conditional logic

## Tools

- [`tools/`](tools) - Personal scripts (e.g. `tfclean`)
- [`work-task-tracker/`](work-task-tracker) - Excel task tracker for a workplace with no ticketing system
